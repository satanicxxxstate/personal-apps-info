Project Manager

Private desktop tools for organizing work and personal records.

This is the information site for the Google OAuth application named Project Manager. Its Google Cloud project supports separately authorized connections used by the owner's Project Manager and Personal Manager desktop applications.

What the applications do

Project Manager organizes projects, tasks and selected work resources. Personal Manager organizes personal notes, documents, shopping records, reminders and finances. The applications keep their records and account permissions separate.

These applications are maintained for private use. This site provides information about them; it does not offer a public download, a Google sign-in form or access to any user's records.

Optional Google connections

The owner can connect Google accounts to read authorized email, selected calendars, documents, spreadsheets or YouTube information within the relevant application. Email access supports finding messages, order confirmations and receipts. Permissions are requested through Google's own consent screen for the features the user enables.

Where a user explicitly enables mail-management features, additional Gmail permission may support the approved email action. A connection is not blanket permission to send, delete or change messages.

Google grants can be renewed in the background while they remain valid. Access can be revoked at any time in Google Account connections.

Privacy and support

Read the Privacy Policy for data use, storage, retention and revocation details. For account-access questions, use the support email displayed on the application's Google consent screen.
