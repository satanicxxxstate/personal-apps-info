# Personal Apps information pages

Public informational pages for the privately used Project Manager and Personal Manager macOS applications.

This repository contains only static application and privacy information. It contains no application sources, mail content, account credentials, private documents or live application data.

The Google OAuth application currently has the display name `Project Manager`. Its Google Cloud project is shared infrastructure; each desktop application retains its own account permissions and storage.

Publish the repository root with GitHub Pages. The intended home page is `index.html` and the privacy page is `privacy.html`.

These pages do not sign users in and do not grant account access. OAuth authorization remains in Google and the desktop applications.
